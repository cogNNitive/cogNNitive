# NN Page

## NN Page: The levels of cogNNitive
slug:: levels
kind:: concept
order:: 1
summary:: The four levels, from the meta-specification language to your own kNNowledge.

cogNNitive layers its specifications so that each level constrains the next. Everything is plain Markdown.

### The levels

1. Level 0 is defiNNition, the meta-specification language.
2. Level 1 is iNNfo, the concrete specification that defines the root primitives.
3. Level 2 is a bluepriNNt, the schema for one domain, such as a business or a site.
4. Level 3 is kNNowledge, the data you write against a bluepriNNt.

kNNowledge is uncountable. Write "three kNNowledge documents", not "three kNNowledges".

### The container

A domaiNN is the folder that holds kNNowledge, bluepriNNts, sources and related assets. It is itself a kNNowledge document, described by `domaiNN_NN.md`.

### Sources and citations

A source is a raw file with a sidecar. A kNNowledge element cites the exact unit it came from, so every statement can be traced back.
