# Concept Guidance Documentation

## Archetype

### Summary
User or organizational persona experiencing workflow friction.

### Description
The `Archetype` concept models the user profile, industry vertical, and primary operational focus.

### Methodologies
- Define one `Archetype` element per key target user persona.
- Keep `core_focus` concise and outcome-driven.

### Prompts
- "Create an `Archetype` for <role> in <industry>."
- "What are the core pain points for this `Archetype`?"

## PainPoint

### Summary
Operational friction, desynchronization, or overhead suffered by archetypes.

### Description
The `PainPoint` concept captures specific day-to-day friction and its qualitative severity.

### Methodologies
- Link each `PainPoint` to its affected `Archetype` via `target_archetype`.
- State concrete symptoms in `symptom`.

### Prompts
- "Add a `PainPoint` for <Archetype> describing <symptom>."

## Pipeline

### Summary
Core lifecycle phase of knowledge processing (Import, Manage, Export).

### Description
The `Pipeline` concept defines system action stages and capabilities addressing pain points.

### Methodologies
- Categorize phases strictly into Import, Manage, or Export.

### Prompts
- "Which `Pipeline` phase addresses <PainPoint>?"

## Deliverable

### Summary
Tangible output artifact generated by the platform.

### Description
The `Deliverable` concept models the format and consumer audience for generated artifacts.

### Methodologies
- Specify explicit output format and target stakeholder.

### Prompts
- "List all `Deliverable` outputs for <Archetype>."

## ValueMetric

### Summary
Quantifiable speedup and strategic return on investment.

### Description
The `ValueMetric` concept captures measurable time savings and qualitative strategic business ROI.

### Methodologies
- Quantify time reduction and qualitative ROI.

### Prompts
- "What is the strategic ROI of <ValueMetric>?"
