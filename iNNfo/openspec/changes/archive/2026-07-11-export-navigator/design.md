# Design: Export Navigator

## Component Architecture

### New: `ExportNavigator.vue`

```
apps/innfo-editor/src/components/editor/ExportNavigator.vue
```

Stateful component. On mount / when workspace changes:
  1. Reads `workspaceStore.handle` → `getDirectoryHandle('traNNsform')` → `getDirectoryHandle('outputs')` → scan `.html` files
  2. For each file, reads first 2048 bytes, extracts `export-meta` JSON via regex
  3. Compares `modelVersion` against current model version from `parseFormatFilename(modelFilename)`
  4. Renders file list with status badges

Internal types:

```typescript
interface ExportFile {
  name: string
  handle: FileSystemFileHandle
  meta: ExportMeta | null
  status: 'current' | 'outdated' | 'unknown' | 'no-model'
}

interface ExportMeta {
  modelName: string
  modelVersion: string
  templateName: string
  exportedAt: string
}
```

Template: flat list with export name, version badge, export date. Each row clickable → opens new tab.

## Data Flow

```
Workspace FSA handle
  → ExportNavigator.getDirectoryHandle('traNNsform')
    → getDirectoryHandle('outputs')
      → values().filter(.html)
        → for each: file.slice(0, 2048) → text → regex /<script id="export-meta"[^>]*>(.*?)<\/script>/
          → JSON.parse → ExportMeta
          → parseFormatFilename(currentModelPath) → currentVersion
          → compare → status
```

## Version Comparison

```typescript
function getExportStatus(meta: ExportMeta | null, currentModelPath: string | null): 'current' | 'outdated' | 'unknown' | 'no-model' {
  if (!currentModelPath) return 'no-model'
  if (!meta) return 'unknown'
  const parsed = parseFormatFilename(currentModelPath)
  if (!parsed) return 'unknown'
  const currentVer = formatVersionString(parsed.version)
  return meta.modelVersion === currentVer ? 'current' : 'outdated'
}
```

## Metadata Contract (app ↔ agent)

Every export HTML generated by the AI agent via traNNsform MUST include in `<head>`:

```html
<script id="export-meta" type="application/json">
{
  "modelName": "Ghostbusters",
  "modelVersion": "V_0-1-2",
  "templateName": "business",
  "exportedAt": "2026-07-11T10:00:00Z"
}
</script>
```

## File Naming Convention

`<ModelBaseName>_V<version>_<templateName>_visualizer.html`

Example: `Ghostbusters_V0-1-2_business_visualizer.html`
