## Gotchas

- `.claude/hooks/block-dangerous-git.mjs` blocks `checkout`/`restore` of `.`,
  `stash`, `reset --hard`, `clean` (and any command text quoting them). Files
  regenerated by verify (e.g. `skills/nn-upgrade/scripts/lib/legacy-migrate.generated.cjs`)
  were NOT restorable during this change: `AGENTS.md` lists
  `git checkout HEAD -- <explicit/path>` as the allowed single-file revert, but in
  the Claude Code session a separate "CC Safety Net" hook blocked both that form
  and `git restore -- <path>`. Workaround used: commit the file as a checkpoint
  and merge `dev` (the tree then equals `dev`). Do not bypass the hook.
- Never run `npm ci` / `npm install` from a worktree: `node_modules` are junctions
  to the primary checkout and get corrupted. Builds only.
- Real-package tests that fall through to `~/.agents` installs are
  machine-dependent; re-run with empty `HOME`/`USERPROFILE` before trusting green.
- `dev` moves between verify and push: merge and push in one step.
- Sibling sessions archive untracked openspec drafts: commit new changes with
  explicit paths promptly.
