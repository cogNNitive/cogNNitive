Knowledge-unit badges

Mockup: every unit is drawn by one builder. A single borderless "+" beside the badge opens a floating flyout below it — info · sheet · citations · edit. The sheet opens a modal with the unit's full data.

Containers

One border at twice the line width — no double border. They hold other units; info only for now.

Structure (from the bluepriNNt)

Solid border in the concept colour, mono font. In review mode the pencil appears only when "Edit structure" is on.

Content (from the kNNowledge document)

No border: the text and the concept icon take the colour of the concept the unit belongs to. Field values, marker values, references and matrix cells are all one kind: value, with a type.

Sources

Paper fill, never tinted. Same solid rule for structure and no border for content, but never editable: they are cited evidence.

Citations (provenance)

One icon per distinct provenance, in canonical order — the icon and its colour say whether the claim came from a human or an agent. Same tokens and same icons as the real console.

Click any citation icon on this page — or the button below — to open the redesigned citations dialog.

In context: an element card

The old name: value badge becomes two units side by side, each with its own address and actions.

In context: a matrix

The axes are structure, the cells are content. Every cell is the same value (number), so the type is stated here once and not repeated on each cell.

In context: a CSV source

Same grid, but read-only: info only, in both modes. Cells are all value (text) — stated once, not per cell.
