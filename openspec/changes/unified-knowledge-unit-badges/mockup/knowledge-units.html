Knowledge-unit badges

Mockup: every unit is drawn by one builder. A single "+" beside the badge opens a floating flyout below it — info · citations · edit.

Containers

One border at twice the line width — no double border. They hold other units; info only for now.

Structure (from the bluepriNNt)

Solid border in the concept colour, mono font. In review mode the pencil appears only when "Edit structure" is on.

Content (from the kNNowledge document)

No border: the text and the concept icon take the colour of the concept the unit belongs to. Field values, marker values, references and matrix cells are all one kind: value, with a type.

Sources

Paper fill, never tinted. Same solid rule for structure and no border for content, but never editable: they are cited evidence.

Citations (provenance)

Missing from the old mockup. One icon per distinct provenance, in canonical order — the icon and its colour say whether the claim came from a human or an agent. Same tokens and same icons as the real console.
